# CTRLZ-Barbershop



Aplicación para la gestión de una barbería hecha en python. Cuenta con una interfaz gráfica para facilitar su uso.

## Características Actuales:
- Base de datos SQLite
- Interfaz gráfica con PySide6
- Sistema de citas
- Reportes por SMTP
